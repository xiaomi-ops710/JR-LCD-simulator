# JR VIS 車内案内ディスプレイ 再現シミュレーター

GitHub Pages で公開する静的サイトです。ビルド工具は使いません。

## ファイル構成

```
index.html            骨組み（画面のマークアップ）
css/style.css         スタイル
js/01-data.js         路線・駅・プリセットのデータ
js/02-state.js        状態管理と描画の中核（renderLCD）
js/03-views.js        本体ビュー群と路線ナビゲーション
js/04-playback.js     列車進行・自動シミュレーション
js/05-controls.js     言語・プリセット・駅編集・時計・イベント登録
uploads/              ここに zip を置くと自動で展開・デプロイされる
.github/workflows/    デプロイ用ワークフロー
```

JS は順番に読み込まれる通常のスクリプトです。読み込み順（01〜05）を変えると動かなくなるので注意してください。

## 開発者向け

機能追加や修正の手順は `docs/DEVELOPMENT.md` を参照してください。回帰テストは `python3 tests/snapshot.py` で実行できます。

## 初回セットアップ（一度だけ）

1. GitHub のリポジトリの Settings → Pages を開き、Source を **GitHub Actions** に変更する。
2. このフォルダの中身（`.github` フォルダを含む）をリポジトリのルートにアップロードして main にコミットする。
   - `.github/workflows/deploy.yml` が見えない場合は、「Add file → Create new file」で同じパスとして作成し、内容を貼り付けてください。
3. 数分後、Actions タブでデプロイ完了を確認し、表示された URL を開く。

## 更新の方法（zip を使う場合）

1. このフォルダ全体を zip に圧縮する（フォルダごと圧縮しても、中身だけ圧縮しても構いません）。
2. リポジトリの `uploads/` フォルダに zip をドラッグ＆ドロップし、main にコミットする。
3. ワークフローが zip を展開してルートに反映し、デプロイまで自動で行います。展開後の zip は自動で削除されます。

ファイルを直接編集して main に push した場合も、同じワークフローでデプロイされます。

## 注意

- 展開時、zip に含まれないファイルは削除されます（`uploads/` `.github/` `.git/` だけは残ります）。
- main ブランチに保護ルール（直接 push 禁止など）を設定している場合は、ワークフローの push が失敗します。その場合は保護ルールを調整してください。
- ローカルで確認する場合は `file://` ではなく、`python3 -m http.server` などのローカルサーバーで開いてください。
